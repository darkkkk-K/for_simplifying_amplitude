# 简历项目描述参考

项目名称：基于Transformer与强化学习的散射振幅符号化简

- 构建两阶段神经符号系统：使用768维Transformer和监督对比学习编码恒等式关联结构，并以聚类可视化展示代数关联、外线数与量纲信息。
- 设计合法动作枚举与动作条件策略网络，融合预训练表示、括号指数和表达式上下文，采用PPO-Clip、GAE及actor–critic学习恒等式操作，训练encoder之后约361万参数。
- 在1024条21–40项的四点随机构型振幅上，以top-k=4、64步推理实现平均82.24%减项，平均项数27.24→4.90；交付模型权重、数据、推理脚本和可复现实验结果。

技术关键词：Python / PyTorch / Transformer / 监督对比学习 / PPO / GAE / 符号代数 / spinor-helicity。
