# 当前网络架构与训练方法

系统先通过监督对比预训练学习代数表示，再冻结encoder，通过PPO学习恒等式操作顺序。符号表达式由旋量括号`<ij>`与`[ij]`及整数系数组成；同一表达式中各项满足统一量纲和螺旋度构型。

## 预训练encoder

`models/encoder.py::ClusteringMachine1_RoPE`独立编码每一项。输入为token序列，模型采用768维、3层、8头、FFN3072及可学习RoPE。有效token输出求和后进行L2归一化，得到项向量。

`data/generation.py`根据外线数、量纲、螺旋度生成合法构型，并通过Schouten和动量守恒构造关联项组。`training/loss.py::NTXentloss`使用温度0.15的监督对比目标，将组内项的余弦相似度提高。`training/pretrain.py`组织AdamW、线性预热、余弦学习率调度和验证。

## 策略与价值网络

当前网络定义在`models/policy.py::RestrictedActorCritic`。输入包括当前完整表达式、合法动作以及历史最小项数。程序先从每项中枚举结构合法的括号因子对，再由策略评分。

每项32维代数特征包含30种规范括号的幂次、系数符号与相对系数大小。追加3维外线数one-hot后，经35→64→64的MLP编码。表达式内项重排通过共享逐项计算、项间自注意力与集合汇聚处理。

令`B`为批大小、`T`为项数、`S`为项内token数、`M`为batch内合法动作总数：

| 层与计算 | 输出张量 |
|---|---|
| 冻结768维encoder | `[B,T,S,768]` |
| 768→512投影；有效token求和并归一化 | `[B,T,S,512]`、`[B,T,512]` |
| 35维代数/点数特征MLP | `[B,T,64]` |
| 拼接576维→512；一层项间Transformer | `[B,T,512]` |
| 融合项上下文；512→256；一层项内Transformer | `[B,T,S,256]` |
| 动作表读取项与两个括号表示 | `[M,298]` |
| 策略MLP 298→64→32→1；按表达式补齐 | `[B,A_max]` logits及mask |
| 价值MLP 581→128→64→1 | `[B]` |

298维动作输入由项摘要64维、全局摘要64维、括号对表示96维、动作代数特征69维和5维上下文组成。括号对使用两向量的和、绝对差及逐元素积组合。5维上下文为外线数one-hot、`log1p(当前项数)`与`log1p(历史最小项数)`。

价值头输入由项间摘要512维、代数摘要64维与5维上下文拼接。encoder保持冻结，其后3,606,435个参数可训练。策略文件使用`expression_best_v1`格式，与配套encoder共同加载。

## PPO、GAE和奖励

当前训练预设为32条采样流，每条24次真实转移，每轮合计768条；每轮重新抽取初始振幅。零表达式、无合法动作或容量结束后，换训练输入补足真实转移。每条流分别计算GAE，真正终止处断开，未终止窗口尾部使用价值bootstrap。

```text
GAE λ=0.93，γ=1
PPO clip=0.2，batch_size=16，epoch=2
每轮768÷16×2=96次更新
loss = PPO_clip_loss + 0.5×value_MSE − 0.001×entropy
```

`training/ppo.py`重用当前top-k条件概率、GAE、PPO裁剪、价值误差和熵计算。训练top-k=8，AdamW学习率1e-4，梯度范数裁剪0.5。每次更新只重算可训练表示，冻结encoder的输出在rollout内复用。

`training/rewards.py`单独维护检查点与奖励历史。对24步、β=0.4，检查点为10、16、20、22、23、24：

- 主奖励：历史最小项数的刷新量除以初始项数。
- 分段奖励：在检查点支付累计奖金的变化，鼓励更早达到更短表达式。
- PBRS：冻结encoder势函数的差分，内部系数0.25，并按初始项数缩放；终止后继势函数为0。
- 扩项惩罚：`−c_punishment×(当前步/24)×max(当前项数−上一检查点项数,0)/初始项数`。

当前`c_punishment=1.5`。势函数结合项向量余弦、括号指数距离和量纲/螺旋度兼容性。预算、检查点及奖励历史由训练环境维护；网络上下文保持上述5维。

`configs/ppo.json`示例按24:4:4采样三个池：五点量纲4–5、四点量纲10–11、四点量纲6–9。每轮先预留全部32个初始来源，再处理提前终止的补采。`scripts/train_ppo.py`记录每4轮真实episode末状态减项率、loss和调用计数，保存模型与完整恢复文件。

## 推理

`scripts/simplify_policy.py`默认加载发布的768维encoder与96轮策略。输入`SpExpr`、外线数、topk与预算步数；每步选择一个合法动作，符号引擎执行返回的首个后继。维护路径上项数最少的表达式，并在结束时返回它。`topk=1`使用argmax，`topk>1`使用条件softmax采样。
